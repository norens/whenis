# @whenis/locale-uk

Ukrainian locale for [whenis](../../README.md). Provides `uk: Locale` with full inflected forms of months and weekdays, pointers («наступний/минулий/цей»), connectors («з / до / по»), time units, and immediate keywords («сьогодні / завтра / вчора»). Includes apostrophe normalisation preprocess (handles iOS smart-quote auto-correct).
