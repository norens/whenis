# whenis v0.2 backlog — gaps found during hutshub-chatbot integration smoke

Source: `DateResolverService.test.ts` (120 tests, 120/120 passing after adapter workarounds).

All gaps below were bridged by legacy regex/Luxon logic in the adapter. They are v0.2 work, not blockers.

---

## GAP-1: No ISO date passthrough rule

**Pattern:** `2026-08-15` (YYYY-MM-DD)
**Tests affected:** `ISO passthrough → unchanged`, `past-date guard` suite
**Missing:** A base rule that recognises an ISO 8601 date token and produces `{ type: 'absolute', year, month, day }`.
**v0.2 work:** Add `isoDateRule` to base-rules; handle past-date guard in the resolver or via an enricher.

---

## GAP-2: No numeric date formats (DD.MM, DD.MM.YYYY, DD.MM-DD.MM)

**Pattern:** `15.07`, `12.06.2025`, `12.06-22.06`
**Tests affected:** `DD.MM formats (HH-2886)` suite (7 tests)
**Missing:** Rules/tokenizer for dot-separated numeric dates, year-rollover logic for past DD.MM.
**v0.2 work:** Add numeric-date tokenizer phase + rules for the three forms.

---

## GAP-3: `позавтра` not in lexicon

**Pattern:** `позавтра`
**Tests affected:** `позавтра / післязавтра → +2 days`
**Note:** `після` (as part of `після свят`) and `після` separately exist. `позавтра` was not added.
**v0.2 work:** Add `'позавтра'` → `{ kind: 'Literal', text: '__day_after_tomorrow__' }` to `ukLexicon`.

---

## GAP-4: `ці` (plural this-pointer) not in lexicon

**Pattern:** `ці вихідні` (these/this weekend), `ці`
**Tests affected:** `ці вихідні from Wed/Fri → current week's Sat-Sun` (2 tests)
**Missing:** `ці` → `{ kind: 'Pointer', direction: 'this' }` entry in `ukLexicon`. Only singular forms (`цей`, `цю`, `цього`) are present.
**v0.2 work:** Add `'ці'`, `'цих'`, `'цими'` to lexicon as `Pointer:this`.

---

## GAP-5: Ukrainian word-numbers as Numeral tokens

**Pattern:** `через два тижні`, `через три дні`, `через сім тижнів`
**Tests affected:** `через два тижні → +14 days`
**Missing:** Ukrainian word-numerals (`один`, `два`, `три`, `чотири`, `п'ять`, …) are not in the lexicon as `{ kind: 'Numeral', value: N }` tags. `ukThroughNRule` requires a `Numeral` token, so only digit forms (`через 2 тижні`) work.
**v0.2 work:** Add word-numeral entries to `ukLexicon` (up to ~20, genitive variants).

---

## GAP-6: No bare "через тиждень" (without explicit numeral)

**Pattern:** `через тиждень`
**Tests affected:** `через тиждень → +7 days`
**Missing:** `ukThroughNRule` pattern is `Grabber:in + Numeral + TimeUnit`. The bare form has no Numeral token. `тиждень` (TimeUnit:week) arrives after `через` (Grabber:in) but with no numeral in between, so the rule doesn't fire.
**v0.2 work:** Add a `ukThroughWeekBareRule` that matches `Grabber:in + TimeUnit:week` and produces `{ type: 'relative', offset: { weeks: 1 }, direction: 'future' }`.

---

## GAP-7: English locale not loaded by default

**Patterns:** `tomorrow`, `next Friday`, `this weekend`, `next weekend`
**Tests affected:** `English phrases` suite (4 tests) + apostrophe variants via English keywords
**Missing:** Locale-en is a separate package and was not included in the hutshub-chatbot parser instance. Some English keywords (`this/next` + weekday) also conflict with Ukrainian Grabber tokens in the merged lexicon when locale-en is absent.
**v0.2 work:** Either bundle locale-en by default in the hutshub integration, or document that both locales must be passed: `createParser({ locales: [uk, en], ... })`. Note: `ResolverCtx` currently only accepts a single locale — multi-locale merge may need API changes.

---

## GAP-8: "wpродовж наступних N днів" — "наступних" interferes with window rule

**Pattern:** `впродовж наступних 3 днів`
**Tests affected:** `'впродовж наступних 3 днів' → 3-day window`
**Root cause:** `наступних` is tagged as `Grabber:next`. The `windowWithinNRule` pattern is `Grabber:within + Numeral + TimeUnit`. With `наступних` in between, only `3 днів` (Numeral + TimeUnit) gets matched by a different rule as a duration.
**v0.2 work:** Extend `windowWithinNRule` to optionally accept a `Grabber:next` filler token after `Grabber:within`, OR add a dedicated `windowWithinNextNRule` variant.

---

## GAP-9: No "до кінця тижня/місяця" window rule

**Pattern:** `до кінця тижня`, `до кінця місяця`
**Tests affected:** `до кінця тижня/місяця — window` suite (2 tests)
**Missing:** No rule for "until end of [week/month]" producing a window. `до` is a `Connector:to` but `кінця` is untagged.
**v0.2 work:** Add tags for `кінця`, `кінець` (end-of-period marker) and a rule that produces `{ type: 'window', from: today, to: end-of-week/month }`.

---

## GAP-10: No combined date+duration rule ("з 5 червня на 3 ночі")

**Pattern:** `з 5 червня на 3 ночі`, `5 червня на 2 ночі`
**Tests affected:** `<date> на N ночей — combined intent` suite (2 tests)
**Missing:** A rule that sequences `ukDayMonthRule` (absolute date) + `stayDurationRule` (duration) into a single `range` node with `nights`. Currently the two rules fire independently; the adapter sees only the first match.
**v0.2 work:** Add `bookingDateWithNightsRule` that matches `Connector:from? + Numeral + MonthName + Connector:na + Numeral + TimeUnit:night/day` and produces a `range` node with nights embedded.

---

## GAP-11: No "останні вихідні [місяця]" rule (last weekend of month)

**Pattern:** `останні вихідні травня`, `останні вихідні`
**Tests affected:** `останні вихідні *` suite (5 tests)
**Missing:** `останн*` is untagged (not a Grabber modifier). No rule for "last weekend of named or current month".
**v0.2 work:** Add `'останній'/'остання'/'останні'/'останніх'` → `{ kind: 'Grabber', modifier: 'last' }` to lexicon and a `weekendLastMonthRule` in the booking plugin that walks back from end-of-month to find Saturday.

---

## Adapter workarounds summary

All gaps bridged in `hutshub-chatbot/src/services/tools/DateResolverService.ts`:
- Gaps 1–3: pre-whenis regex matching (legacy logic preserved verbatim)
- Gaps 4, 8, 9, 11: pre-whenis regex (before parser.parse call)
- Gaps 5–6: pre-whenis regex fallback (parseUkrInteger)
- Gap 7: pre-whenis English keyword matching
- Gap 10: pre-whenis combined regex

Total adapter lines that bypass whenis: ~90 lines of legacy logic.
Lines delegated to whenis successfully: today, tomorrow (uk), yesterday, next/this weekday (uk),
  через N днів/тижнів (digit), з A до B місяць, з A по B місяць, на N ночей,
  впродовж N днів, у найближчі N днів, на свята/після свят.
